CareSaathi reimagines elder care by keeping elders empowered, not replaced. Built for Catalyst Hackathon 2026.

### 🔴 Problem
- 60% elders miss medicines due to forgetfulness or complex schedules
- Existing apps either isolate elders or let family take over completely, removing elder autonomy
- No structured escalation when doses are missed

### 🟢 Our Solution
A family-connected platform where **Elder approves, Family supports.**

### ✨ Key Features

| Feature | Description |
| :--- | :--- |
| **👴 Elder Approval System** | Caretaker can only REQUEST changes. Elder APPROVES. Final control stays with Elder. |
| **🚨 3-Level Missed Dose Escalation** | L1: Gentle Reminder to Elder → L2: Email Alert to Caretaker → L3: SOS to Family Circle |
| **📊 Weekly AI Report (Gemini)** | Adherence %, Missed Patterns, Upcoming Appointments - Powered by Gemini AI |
| **👨‍👩‍👧 Family Circle Code** | One code connects entire family with real-time Activity Log |
| **📸 Prescription Scan** | Upload prescription image → Gemini Vision auto-extracts medicines |
| **🌐 Multilingual** | English, हिंदी, Hinglish for Bharat |
| **💊 Demo Ready** | 5 Medicines + 2 Appointments pre-loaded for jury evaluation |

### 📱 How It Works
1.  Elder creates a Family Circle and gets a unique Circle Code
2.  Family members join as Caretakers using the Code
3.  Track medicines, appointments, and daily activity together
4.  Elder retains final approval power for all changes

### 🎯 Impact
Empowering 100M+ elders in India to manage their health with dignity while keeping families connected and informed.
